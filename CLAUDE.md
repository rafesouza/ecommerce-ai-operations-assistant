
# E-commerce AI Operations Assistant

## Objective
Build a professional e-commerce operations and analytics platform with future AI capabilities.

## Technology Stack
- Python 3.13
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker Compose
- React and TypeScript (future phase)
- MCP and AI integration (future phase)

## Development Instructions
- Explain all technical decisions in Brazilian Portuguese.
- Implement one feature at a time.
- Follow clean code principles.
- Use Python type hints.
- Write automated tests.
- Keep the architecture simple and modular.
- Never store credentials or secrets in source code.
- Use synthetic data during development.
- Ask before destructive operations.
- Do not implement future modules without approval.

## Learning Approach
The project owner is a Software Engineering undergraduate.

Explain each implementation clearly, including:
1. What we are building.
2. Why it is necessary.
3. Which files will change.
4. How to test the implementation.
5. What technical concepts were learned.

## Current Milestone
Create a minimal FastAPI backend connected to PostgreSQL.

Success criteria:
- API starts successfully.
- GET /health responds correctly.
- PostgreSQL runs through Docker.
- Database connectivity is verified.
- Automated tests pass.
