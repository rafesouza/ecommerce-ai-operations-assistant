
# E-commerce AI Operations Assistant

An AI-powered e-commerce operations and analytics platform.

## Project Overview

E-commerce AI Operations Assistant is a software engineering portfolio project designed to explore how artificial intelligence, databases, and automation can improve e-commerce operations.

The project focuses on order management, inventory monitoring, sales analytics, logistics, and AI-assisted decision-making.

## Project Goals

- Build a modular e-commerce operations platform.
- Develop REST APIs using Python and FastAPI.
- Store and query structured data using PostgreSQL.
- Create an interactive dashboard using React and TypeScript.
- Explore AI integration and the Model Context Protocol (MCP).
- Apply software engineering best practices, testing, and version control.

## Planned Technology Stack

| Technology | Purpose |
|---|---|
| Python | Backend development |
| FastAPI | REST API |
| PostgreSQL | Relational database |
| React + TypeScript | Web interface |
